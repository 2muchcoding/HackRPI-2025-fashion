# Fashion Through Time

Fashion Through Time is a web application developed during **HackRPI 2025** that helps users explore clothing styles and discover fashion inspiration through a modern, interactive interface. The project was created during a hackathon to demonstrate rapid software development, collaboration, and modern web technologies.

## Overview

Finding clothing that matches a specific aesthetic often requires searching across multiple websites. Fashion Through Time simplifies this process by allowing users to browse fashion styles through a single interface.

Built during a 24-hour hackathon, the project focused on creating a clean user experience while learning new technologies and collaborating effectively under a tight deadline.

## Features

- Modern responsive user interface
- Browse clothing styles and fashion inspiration
- Interactive frontend built with React and TypeScript
- Fast development using Vite
- Component-based architecture
- Clean and responsive design with Tailwind CSS

## Running the Project

Clone the repository:

```bash
git clone https://github.com/2muchcoding/HackRPI-2025.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
